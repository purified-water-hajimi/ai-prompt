# ai-prompt

> 我平时用 AI 干活时，反复用到的几条提示词。每条都能直接复制去用。
>
> 写下来的原因很简单：**好用的 prompt 不该每次现编。**

## 为什么是这三条

大部分人和 AI 协作，卡在三个地方：

### 一上来就让写代码 → 白写

```
❌ "帮我做一个 XXX"
✅ 先问：GitHub 上有没有现成的？维护得怎么样？要不要二改？
```

**省下的不是 token，是返工的时间。**

### AI 一次做完 → 你什么也没学到

```
❌ 两千行代码拍过来，复制粘贴交差
✅ 每步先问你"你打算怎么做"，答错的也先让你说完
```

**错一次比看十遍正确答案记得牢。**

### 聊了一周 → 没沉淀

```
❌ 每次都从零开始解释
✅ 每周复盘一次，把有效的做法固定下来
```

## 使用方法

1. 打开任意一条 prompt 文件；
2. 复制里面的**代码块**（那一段才是真正发给 AI 的）；
3. 把 `【XXX】` 换成你的具体情况；
4. 发出去。

> 每个文件里除了 prompt 本身，还写了**为什么这么设计**——想改的话照着改，别只抄字面。

---

## 三条共同的思路

| 原则 | 意思 |
|---|---|
| **先想清楚再动手** | 调研、架构先行，别一上来写代码 |
| **留出人的位置** | 每步都要你输出，AI 不替你想 |
| **过程要沉淀** | 知识清单、自测题、复盘——让下次更快 |

## 一点说明

- 这些 prompt 是为**通用场景**写的，没有绑定某个模型，DeepSeek / GPT / Claude 都能用。
- 里面没有"魔法咒语"，靠的是**流程设计**：分工、节奏、验收标准。
- 想改成自己的版本，直接改就行。
