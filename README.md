# ai-prompt

我常用的 AI 提示词集合。每条都能直接复制去用。

## 目录

| 文件 | 用途 |
|---|---|
| [项目创建prompt-省token版.md](./项目创建prompt-省token版.md) | 动手写代码前，先让 AI 调研 GitHub 上有没有现成轮子，再决定「复用 / 二改 / 从零写」 |
| [周复盘prompt.md](./周复盘prompt.md) | 每周日让 AI 把这一周的对话复盘成人设补丁建议 |
| [学习型协作prompt.md](./学习型协作prompt.md) | 让 AI 陪你做任务而不是替你做，做完还能留下知识清单 |

## 使用约定

- 每个文件都包含：**用途**、**可直接复制的 prompt 全文**、**为什么这么写**
- 需要填的变量统一用 `【XXX】` 标注
- 新加一条就新建一个 md，并在上面的表格里补一行
